### Why I Built This

I have years of notebooks from high school and university collecting dust on my bookshelf.

All of them are love of mine, I spent a lot of my time creating them, memorising them, and hoping to use them to smash some exams. Unfortunately, four years away from high school and six months away from uni, I realise I rarely touch them anymore. They have fulfilled their purpose, but I don't want to just throw them away.

Instead of letting them collect more dust, I wanted to turn them into a simple digital notebook library.

Check out my [digital notebook website](https://kukustudy.github.io/my-digital-notebooks/) !


### 1. Prepare The PDFs

First, I made sure all my scanned notebooks were stored in one GitHub repository.

The collection covers **2017–2025**, including high school and university notes. I try to name them in certain patterns to keep things organised.

I used the iPhone's native Files app to do all the scanning.

### 2. Create The Website

For the user interface, I kept the website simple with three files:

```text
index.html
style.css
script.js
```

All the code was generated by ChatGPT.

The prompt I used:

```bash

I have stored all my scanned notebooks from high school and uni in this github repo [link to your github repository], could you help me create a simple one page static frontend page that can present these notes in an more organised way? I want to host it in github

```

The website displays my notebooks as cards and allows me to preview each PDF directly in the browser.

### 3. Preview The Website Locally

Before pushing anything to GitHub, I tested the website locally.

I opened a new terminal in VS code and open the html page with below command:

```bash
open index.html
```

This will open the file in my local browser

### 4. Restyle

After testing, I fixed a few PDF filename issues and used ChatGPT to help update the design.

I found that the design generated by ChatGPT is bit generic and not in the style I want, so I redesigned it by defining a theme color, and asked it to reposition some elements.

I chose <span style="color: #86C166;">#86C166</span> as the main colour and added:

Search
Notebook cards
PDF preview
Mobile responsiveness
Collection statistics

Something to note is that after you make changes, make sure you refresh the page to see the changes, as this is not a fancy frontend framework and does not do auto-reload.

### 5. Save Changes And Push To GitHub

Once everything worked locally, in your VS Code terminal:

```bash
git add .
git commit -m "Create digital notebooks website"
git push origin main
```

### 6. Create/Enable GitHub Pages

For those who don't know, GitHub Pages is a feature of GitHub that allows you to host your website, however, it only allows you to host static page like html, but not backend server or database. However for the purpose of this project, this feature is MORE THAN USEFUL! 

To enable this feature, go to the GitHub repository:

**Settings → Pages → Build and deployment**

I selected:

```text
Source: Deploy from a branch
Branch: main
Folder: / (root)
```

After GitHub finished deploying, my repository became a website where I can browse and preview my notebooks from high school and university. 

### How long did it took me to finish this little project?

Preparing the PDFs took about 5–8 hours, as I was digging through my bookshelf and figuring out what should be kept and what shouldn't. Scanning the pages was a bit lengthy as well.

But in terms of creating the frontend design with ChatGPT and prompting it into something I like and approve, it only took 60 minutes of my precious weekend time, and I was rewarded with a much cleaner bookshelf!

Imagine being able to carry your notebooks anywhere you go! 📚 If I had all the money and time in the world, it would be fun to try to create an AI agent using all the notebooks I have.

If you would like to digitalise your notebooks in the same way, just follow the steps above!
